# 新闻展示与宏观事件归类的通用规则

原来的两个问题是：上市代码清理逐家公司列举；宏观标题由关键词命中顺序决定。遇到新公司或同一段中的背景信息时，容易遗漏清理、误用标题或拆开同类项。

本次把展示元数据、事件分类和事实授权分开。公司动态、宏观、人物、前沿动态仍统一通过 `grounded_text` 校验来源，再调用 `present`。分类结果不具备授权摘要或长期判断的能力。

## 展示契约 v3

- 交易所限定、证券代码标签、已知上市后缀采用共同语法，不依赖公司名单。
- `(MA)` 一类裸缩写只有紧邻匹配的持仓公司名称时才去除。公司英文名和共享中文展示名提供身份元数据；`(AI)`、`(EPS)`、事实括号、未知缩写保留。
- 来源尾标依据来源字段及媒体别名处理，只删除末尾分隔的来源标签，保留句内报道归属。
- 阅读引导采用完整末句结构识别；跟随实际日期、金额或事实的内容不删。
- 人物署名依赖明确的发言人身份及通用职务、归属语法，不为某个人单写规则；否认、警告、他人转述和时间上下文保留。
- `presentation_version` 与 `presentation_operations` 记录实际发生的转换；原始标题、摘要、证据摘录及已核验译文不覆盖。
- v1/v2 使用冻结的 `legacy_news_presentation` 复核历史映射。新发表内容使用 v3。以后改变展示契约（包括影响输出的词汇表）应升级版本并增加回放测试，不能直接改旧版规则。

公司中文展示名称有一个共同的数据表，提示词与上市元数据识别共用。专名翻译表仍是有限词汇表；这与每家公司单写一个清理分支不同。

## 宏观事件契约 v1

`macro_events` 从已核验的展示文本抽取对象、动作、主体类别、地域、时间及状态。每个识别片段都记录原文及字符位置。主句/背景句和同句范围限定关系绑定：

- 央行名称单独出现，不足以证明这是利率政策事件；公司贷款利率不能借用另一句中的央行名称。
- 政府预算和公司预算区分；有实际国防合同/开支关系才归入国防开支。
- 美债、政策利率、通胀等对象按主句及动作关系竞争，背景里的油价或央行名称不再靠词表顺序决定标题。
- 地域与事件类别共同决定区域主题；同一期的省略式双边谈判后续可通过上下文归组，决策原因单独留档。
- 同主题跨来源合并，每一条事实及其引用仍独立。数字、日期、否定和计划状态不同的事实不因主题相同而删除。
- 无法识别的事实保持独立；不凭相同的“宏观观察”标题强行建立关系。最终仍只取最重要的三个主题，不补足段落。

证据映射新增 `macro_event`（含版本、片段和归类原因），便于直接追查误分类。长期判断继续要求正文与原始来源的逐行绑定，不能拿事件标签代替来源证明。

## 验证与边界

新增跨实体和反例测试：陌生公司/媒体、多个交易所、不同人物与职务、不同国家预算、主从句换序、跨句央行干扰、词语子串、美元与金额误识别，以及历史版本回放。

对 run 36642819586 已发表的 13 条归档来源进行离线回放，全部证据映射可复核，所有原有链接保留，宏观合并为通胀与中东两个主题。预览 HTML 为 90,745 bytes（本地归档预览原为 90,911 bytes；这不是实发 MIME 大小）。未调用 LLM 或 SMTP。回放只覆盖归档已发表来源，不代表重新抓取当天全部候选或逐句验证实收原始邮件。

分类器是可解释的有限双语规则，不是完整自然语言理解器。新颖隐喻、复杂跨句关系、未知地区或公司缩写可能需要新增词汇/语法和跨对象测试。分类不确定时不编造关系，也不通过放宽来源核验来增加内容。
