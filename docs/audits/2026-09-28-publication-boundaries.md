## 问题与修复

1. **周线身份检查缺失（P1）**：日线价格验证证券/币种/交易所，但 yfinance 周线直接进入均线。有效日线搭配另一证券的周线会计算错误买点。现在日线、周线均读取各自历史响应已捕获的 metadata 验证身份；失败走已有 Chart 备路，不调用可能发起新请求的 `history_metadata` 属性。复权口径、均线周期及策略不变。
2. **长期判断记录间借用核验（P1）**：同一 URL/输出有一条合格记录时，另一条原文不匹配的记录可借用映射，并用新日期通过窗口检查。现抽出单条证据核验函数，每条记录独立检查原始完整片段、译文与展示转换、正文出现和来源，不再用同链接的其他记录作担保。
3. **被隐藏新闻仍可支持长期判断（P2）**：前沿模块传入占位语时模板隐藏新闻，但最终闸门仍接受这些新闻作为依据。现在主入口和最终 renderer 都排除占位语隐藏的前沿正文，符合“本期可见正文才有资格支撑判断”的约定。
4. **内容健康状态和缺失分母不完整（P2）**：全来源失败导致候选数为零、情绪说明或长期判断加工失败、取数超时，可能不被 `content.status` 捕捉；空指标集合甚至没有缺失行。新增 `section_health`，记录来源失败、加工失败、占位降级、正常沉默、超时数；行情与情绪按预期清单补缺失行；NaN、无穷值、布尔值不能标成有效行情/指标，指标无效值以 JSON null 留档。
5. **正常沉默误报（P2）**：存在候选但正常筛选后没有重要新闻，过去会仅因刊出数为零被标成失败。现在允许明确完成的正常沉默；部分源失败、加工失败仍单独告警，不因沉默标识被遮蔽。

所有质量状态仍与 SMTP 投递状态独立；未改变自动重发、FORCE_SEND 或收件人行为。
