# 每日期刊全盘审计与修复 · 2026-09-05

## 结论与范围

记录口径：本文的“未发布/未发送”指审计结束时的状态。用户随后已授权将修复发布到 `main` 并向两个指定邮箱正式试发；后续发布结果以 Git 提交与对应 GitHub Actions 运行记录为准。

本轮不是只审计最近几个提交，而是沿「采集 → 校验/备用源 → 估值与信号 → 新闻加工/去重 → 长期判断 → 邮件渲染 → SMTP → 状态持久化 → 工作流/监控」检查当前项目，并修复下表中的 20 类问题或防护缺口。

基线：`cb43229dc3437885e88f5ddc62a5d1b775f0087b`，仓库 `sudsusc-cyber/daily-market-brief`。开始时工作区干净。修复保留在当前本地分支，尚未提交、推送或上线；本轮没有发送邮件、触发正式发送工作流或消耗 LLM 调用额度。

这不是“永久没有 bug”的保证。通过的测试说明本文列出的故障反例和已有回归场景受到了约束，不代表上游网站永不变化、估值永远正确，或所有邮件客户端均已实机验证。

## 防止以后回归的新增措施

1. **默认离线测试护栏**：普通测试阻止 Python socket 和 yfinance 所用原生 libcurl 的未模拟连接。真实 API 测试必须显式使用 `dryrun` 标记，常规 CI 仍排除它们。本轮测试未调用 DeepSeek、行情 API 或 SMTP 服务。该护栏约束进程内测试，不是针对任意子进程的操作系统网络沙箱。
2. **CI 依赖安全门禁**：在推送/PR 的 CI 中加入生产锁定依赖审计，固定审计工具版本。发现已知漏洞会失败；漏洞数据库临时不可访问也不会假装通过。该步骤不进入每天发邮件的执行路径。
3. **可重复的版式对比脚本**：新增 `python -m scripts.audit_preview --baseline <commit>`，用固定时间和样例数据比较基线与当前 renderer/template，避免每次视觉检查被实时行情、日期和头图变动干扰。

## 保留且未擅自改变的规则

- 持仓列表、分组排序、120/200 周与 250 日的策略区别，以及“每天持续显示”。
- KO、BRK.B 的小号防守标签、温度计配色/气泡/指针和已认可的邮件版式。
- 个股 Morningstar 公允价值的上市口径、币种、来源日期与备用缓存规则。
- 泡泡玛特仍明确为大摩目标价参考，不冒称晨星公允价值。
- QQQM 固定乐观情景及确定性计算，不改成加权情景，不让模型随意改公式。
- 邮件 IRR 仍为 `公允价值 / 现价 - 1` 的差额收益率，非真正的年化内部收益率；脚注继续明确说明。这是用户已选择的显示口径，不在本轮自行改名或换模型。
- 日常时间预算、LLM 模型、定时计划、收件人列表、生产环境凭据均未变；本轮不增加日常 LLM 调用次数。
- 只因源故障不会随意把已有合格估值抹掉；也不会为了“永远有数字”把过期/冲突或错误数据伪装为刚刚核验的新值。

## 仍然存在的外部风险与边界

1. **免费上游无法承诺永远最新。** 页面改版、限流、未公开报告或多源真实冲突只能尽量检测、回退和说明，不能靠代码制造不存在的证据。Yahoo 两种抓取方式也不是两个独立数据提供商。
2. **邮件客户端不是浏览器。** 本轮没有在 QQ 邮箱、微信内 QQ 邮箱、iOS、Android 和 Outlook 实机重新收信；没有声称已完成这些实机验收。保留正常样例输出能降低排版回归风险，但不能保证客户端不自行缩放或裁剪。
3. **SMTP 接受不等于进入收件箱。** 邮件可能延迟、被反垃圾过滤或进入垃圾箱；DATA 后连接异常时，是否已接收可能存在不可消除的歧义。已有回执和避免盲目重发的机制保留。
4. **估值模型风险仍在。** QQQM 乐观情景、增长假设以及价格对公允价值的差额，都不是保证收益。相同输入应给出相同结果，但正确执行公式不意味着估值必然准确。
5. **去重是启发式加语义判断，不是数学完备证明。** 已避免若干明显误删/重复场景，但无法承诺任何改写都不重复、任何细小新事实都绝不漏掉。
6. **已知漏洞扫描有时间边界。** 本次为 2026-09-05 可见的公开数据库结果；新 CI 门禁和原有 Dependabot 用来降低未来遗留风险。
