## 已确认的问题

run 36251907277 的最终 HTML 确实刊发了“主权资本正成为云与算力需求的长期买家”。正文的微软条目与这一采购主体判断不符。历史抽取明细未归档，不能断言恢复了该句的实际 LLM 引用链；以真实微软条目构造的离线反例可通过旧提取器，证明 `why_it_matters` 未受原文约束。

## 当前行为

- 保留居中红色一句判断和小字“新证据／新变量”，引用用角标；后台存事实及验证条件，不增加邮件正文解释段。
- 本期可见原文绑定是唯一入口；最终渲染重新派生并比较全部刊发字段。旧 ledger、自由文本、隐藏板块及未展示的第三条前沿新闻不能回退进入邮件。
- 判断只使用七类受控条件句，不包含未经来源支持的新主体、买卖方向、数量或已实现的长期收益。
- 不受主题成熟期和 21 天主题冷却限制；针对已刊发事实去重。模拟连续七天不同事实均可展示，相同事实换 URL 不能重复触发。
- 原始新闻不变，呈现层补齐段末句号，保留问号、感叹号和引号语义；正文角标增加间距，底部来源明确分隔，保留全部链接。
