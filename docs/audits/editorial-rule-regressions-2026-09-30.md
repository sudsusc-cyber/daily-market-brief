# 卷首语与新闻选材规则回归审计

审计起点：`c10c7a1`（PR #112）。对照历史决策记录、最近处理器变更和本地保存的
正式邮件归档，区分用户明确要求的变更、防错带来的功能退化及原有边界。
本次不把“当前选材效果”归因于某一个模型或新闻源，也不声称逐条重建历史未刊候选。

## 规则对照与处理

| 范围 | 原有/已确认规则 | 发现 | 本次处理 |
| --- | --- | --- | --- |
| 卷首语 | 根据持仓信号动态写作；后期约定 60–110 字、克制、有哲理、不复述数量、不建议具体买卖 | #103 删除生成调用，改为计数和固定结尾；多个正式归档完全相同 | 恢复动态生成与 7 天近似重复检查；固定备用文案仅用于失败 |
| 卷首语事实 | 使用逐股实际信号，NONE 不代表高于所有参考线，持续区间不代表新触发 | 旧自由生成曾编造地域分布及参考线关系 | 确定性生成信号背景，模型只写哲思；禁止补充本期行情断言、数字及买卖指令 |
| 宏观选材 | 头版级政策、经济数据、系统性风险和重大地缘变化 | 通用发布提示把译文可用性带进选稿；分类后固定主题优先级可能淘汰模型排在前面的新型事件 | 原文价值与翻译分开；生产保留模型明确的段落重要性顺序，固定主题分数仅作同级/旧格式兜底 |
| 宏观段落 | 用户明确要求同类合并、最多三个最重要主题、不凑数 | 属于已确认的产品规则 | 保留，不恢复更多段落；来源、正文及长期判断映射同步保留/删除 |
| 公司新闻 | 经营业绩、合作、监管、产品、人事、资本动作；排除单纯股价和宣传噪音 | 经营事件与股价变动/奖项共存的标题可能被整条删除；宣传引导后保留事实的逻辑限定了公司名 | 以实际事件与对象关系决定候选资格，不让价格/宣传措辞抹去完整事实；去掉公司名称白名单 |
| 宏观题材 | 按是否有重大政策/市场影响判断 | 熊猫外交直接排除，未检查同条新闻是否还有贸易等实质事件 | 象征性报道仍排除，有明确实质影响则交给选稿判断 |
| 选稿窗口 | 原先每公司前 5 条、每宏观源前 8 条 | 这是较早的限流，不是最近偷偷新增；重要事件可能落在截断之外 | 选稿窗口扩为每公司 15、每宏观源 24；前置翻译仍保持原来的 5/8 窗口，选中后有界补译 |
| 中文发布 | 原始标题/摘要不可变，译文核对数字、单位、对象、状态、条件 | 公司、宏观、前沿仍可能因初次翻译失败丢失已选内容 | 共用有界补译，每次最多 8 条、一次请求 20 秒；同一选稿结果重新核验，不放宽事实要求 |
| 人物/前沿 | 真实本人发言；前沿需对持仓链有实质影响；无重要内容与失败区分 | 近期 #111/#112 已恢复人物原文选稿与翻译 | 保留人物恢复和门槛；前沿补上同类翻译恢复 |
| 长期判断 | 只能依据最终可见正文及原始证据，不得引用隐藏/被删除条目 | 严格映射是用户反复要求的正确性约束 | 保留来源映射与展示边界，不恢复无依据的自由推断 |
| 其他 | 三段上限、新闻时窗、均线/估值口径、情绪确定性分值、发送防重 | 未作为本次选材退化的修复对象 | 本次不修改这些规则，也不增加周末回补或 13F 功能 |

## 运行约束和留档

- 动态卷首语最多两次生成，每次 20 秒，受同一 LLM 总时间与 token 预算约束。
  信号背景分为无买入信号、部分买入区间、全部买入区间及待核验，不能由模型改写。
  风格段仍是自由文本，词法防护不是完整自然语言语义证明。
- 最近七天已发送卷首语进入 prompt 并做文本相似度检测。同日重发也读取现有历史。
  只有 SMTP 发送成功后才写入既有 `published_editorial.json`；预览和发送前失败不消费历史。
- 不增加采集请求。更大的选稿窗口增加 prompt 输入；只有选中的未译候选补译。
  公司、宏观各最多一次补译；前沿每个配置实验室一次；均受原有全局预算限制。
- 宏观/公司/前沿的候选窗口、补译前后诊断进入审计 manifest。宏观部分核验失败
  计入内容质量降级，不能因其余段落成功就掩盖；内容告警不触发 SMTP 重发。
- 宏观重要性仍是编辑判断。固定主题名无法衡量任意新事件的影响，故不凌驾于
  生产模型明确给出的重要性顺序；模型遗漏或误判仍需从运行归档追查。

## 回归范围

覆盖动态文风、各信号状态、实际低于参考线的 NONE、虚构地域/数量/价格状态、
近期重复后的重试、草稿不消费历史；模拟 SMTP 的成功、失败、预览路径。

新闻覆盖跨公司经营事件与价格噪音共存、宣传引导后的完整事实、实质贸易事件、
第 6 条公司新闻和第 9 条宏观新闻可被选中及翻译、未知宏观主题保留其编辑优先级、
最终脚注与长期判断来源一致、前沿翻译失败不吞掉其他实验室的选稿。

历史正式邮件可以证明固定卷首语重复；历史归档只保留部分未刊信息，不能证明本次
发现的所有候选过滤反例都曾发生在某一封实发邮件中。离线测试也不等于实盘选材质量验收。
