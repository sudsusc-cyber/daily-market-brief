# QQQM v1.5 每日公允价值

## 决定

QQQM 不套用个股财报估值政策。每日行情采集到 QQQM 现价后，DeepSeek 只负责从公开来源整理同一数据日的输入并返回引文；最终公允价值和 IRR 永远由 `src/valuation/qqqm.py` 的固定公式计算。

输入为 QQQM 自身价格、Invesco NAV、Nasdaq 100 TTM PE、trailing/forward PE 配对和 TTM 分红。计算固定使用 `E0 = NAV / PE`、市场隐含增速、20%/40%/40% 三情景、10 年现金分红与终值、10% 折现率和 0.15% 费用；IRR 是令公允价值等于当前价格的折现率再扣除费用。

## 数据闸门与降级

- 每个输入字段必须有 HTTPS 引文，数据日不得是未来日期，距北京时间当天最多 14 天；不满足即不采用本次响应。
- DeepSeek 返回空响应、JSON 无效或字段校验失败时，最多沿用 14 天内缓存的完整输入快照；没有有效快照就显示“待更新”，不猜测、不用旧值拼凑。
- 每次日报运行只调用一次 QQQM DeepSeek 输入整理；邮件渲染前的第二遍估值检查复用第一次结果，避免重复消耗额度。
- 现价仍来自行情采集，不允许 DeepSeek 改写；预览样例值不写入生产缓存。
