# ADR-0016：以本期可见事实约束长期跟踪判断

日期：2026-09-26。替代 ADR-0012 的邮件刊发部分。

## 问题与决定

实发 run 36251907277 展示了“主权资本正成为云与算力需求的长期买家”。本期相关正文实际为微软在海湾地区的云与 AI 投资计划，不能支持采购主体和长期订单的推断。旧提取器只核对 `text` 和 URL，邮件却展示独立生成的 `why_it_matters`；另有旧账本回退、没有展示引用及主题级 21 天冷却问题。该 run 没归档完整的 thesis 抽取结果，因此不能声称已恢复模型当时的精确关联。

邮件保留原有居中红色「一句长期判断」+ 小字标记，仅增加来源角标。判断采用代码定义、与事件类别一致的有条件断言（例如“基础设施投入的长期价值取决于资本回报”）；原文事实与后续验证条件只进后台审计，不展开到邮件。

“新变量”用于新产品、支付商业化及监管事项；其他合格事实标“新证据”。标记表示本期新增可追溯的信息，不表示该事实是历史首次发生，也不表示长期结果已得到证明。规则不引入新的采购主体、订单关系、金额、期限或增长结论。

## 来源与发布边界

- 仅使用最终可见的公司新闻、宏观、人物发言、前两条前沿动态。13F 元数据、旧主题、隐藏/降级块不构成依据。
- 原始标题/摘要、完整证据句、经核验译文、展示转换及 URL 必须重新对应；URL 必须存在于同一模块来源中。保留数值、单位、实体、状态等现有核验。
- 事实逐字来自本期正文；发布前重新派生并比较看点的全部字段。不能向最终 renderer 传入任意旧判断绕过验证。
- 看点分类需同时匹配原文与译文，且明确出现相关公司。仅支持投入/产能、授权、支付、新产品、经营数据、资本配置、监管准入七类。匹配决定后续观察什么，不断言买卖关系、订单落地、增长实现或因果关系。
- 不再调用 LLM 生成长期判断。历史研究账本文件和离线研究工具保留，但生产入口不再更新或引用该账本。旧文件不删除、不迁移成已核实断言。

## 频率与发送

- 不要求主题先积累为 core，也不执行 21 天主题冷却。每期最多三个合格的不同事实，按正文顺序选取。
- 对原始证据句的规范化哈希进行 90 天刊发去重；URL、译文或版次改变不刷新同一事实。数字、状态等变化保留为新候选。不同措辞的转载不宣称可被完全识别，上游新闻去重继续生效。
- `state/thesis_publications.json` 仅在 SMTP 接受后记录实际刊发项，失败和仅预览不消耗；正式试发仍按原工作流使用可丢弃状态，不回写生产 daily-state。
- 本期没有可支持的事实时不凑数。该机制消除人为冷却导致的低频，不保证固定每周条数。

## 留档与边界

manifest 新增 `judgment_mapping`（完整原文绑定、事实、看点规则版本、验证条件、URL）及 `judgment_selection`（选取/去重/日期/规则不适用等决定）。不含收件地址或凭据。

这是一种收窄输出范围的正确性保障，不是通用自然语言蕴含证明。保留的上游新闻译文核验也不等于独立确认报道真实性。以后新增看点类别须先补正反例；不得恢复不受约束的自由文本断言。

## 新闻行文与脚注

公司与宏观段落、人物引语、前沿动态在呈现层统一句末标点；问号与感叹号保留语气。原始标题、摘要和证据句不改写。正文连续角标使用一致的左右间距；章节底部来源链接使用独立可换行块及显式分隔符，避免 HTML 压缩或客户端忽略 margin 后粘连。
