# ADR-0017：持仓内在价值 v1

## 决定

- 每只持仓使用 `src/valuation/policy.py` 中固定且版本化的方法。
- `src/valuation/instructions.py` 把逐公司公式、禁用输入和更新节奏写入 DeepSeek
  草稿提示；模型不得自行选择估值方法或补造未披露数据。
- 官方文件发现、哈希核验和最终计算均由 Python 确定性完成；DeepSeek 不得直接写入
  内在价值或隐含收益率。
- 首次建立底稿或出现新财报时，DeepSeek 只能对 Python 基准输入做结构化复核；必须
  返回至少两条带页码/章节的官方原文引文，且冻结字段和五倍数量级保护全部通过才采纳。
  复核失败时使用确定性标准化底稿，不让整封邮件退回空白。
- 每日运行把标准化财务报表转换成 `state/valuation_snapshots.json`。没有新财报时
  重算现价与 IRR；有新财报时自动绑定新文件编号和 SHA-256 后刷新底稿。
- 估值底稿的 `source_document_id` 必须等于本次运行发现的最新官方财务文件。
- 底稿的 SHA-256 必须等于本次下载官方原文的 SHA-256；只匹配文件编号还不够。
- 单一数据源短时失败时沿用上一份可复算底稿，并在运行日志留下原因；无任何历史底稿、
  公式越权或数值不可复算时才允许显示“待更新”。
- 邮件第二行显示大写缩写 `IRR`，替代安全边际；BRK.B 使用固定五年退出 SOTP，显示 `5Y SOTP IRR`。
- 内在价值与现价保持同一展示口径，不加 `$` 或 `HK$` 前缀；币种由标的市场决定。
- TSM 以新台币完成估值，按 1 ADS = 5 普通股和即期汇率换算，不把 ADR 市场溢价写入内在价值。
- 折现率由版本化政策冻结；多数持仓为 10%，TSM/腾讯为 11%，泡泡玛特为 12%。

## 官方数据截止

正式运行在估值准备阶段检查一次官方源，并在渲染前再次检查。两次之间出现新文件时，
旧底稿立即失效。邮件只显示最后一次检查时间。

## 跳变保护

SMTP 成功后记录本次真正发布的内在价值。如果同一官方文件、同一模型版本下，下一次
计算值变动超过 3%，则隐藏该值并标记人工复核。新官方文件或显式模型升级可解释跳变。

BRK.B 的批准底稿必须额外包含五年后、沿用固定倍数的退出 SOTP 每股价值；没有该字段时
显示“待更新”，不以当前资产价值或安全边际猜一个 IRR。

## 股票薪酬与回购

- 股票薪酬视作真实成本，不加回；使用最新报告稀释股数，不预测未来稀释。
- FCFE 不通过预测回购减少未来股份数，避免现金流与股数重复计价。

## 发布条件

新列只有在官方文件、自动或人工底稿、确定性复算三者全部通过时才显示数值。生产仓库
变量 `VALUATION_ENABLED=true` 已启用；本地缺省仍关闭，避免测试时意外联网。
