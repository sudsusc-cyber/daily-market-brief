# 0019 — 港股晨星报告识别与备用读取

日期：2026-09-03。

## 故障与边界

正式定向试发发现了腾讯 2026-09-02 的新报告，但旧解析器只识别
`fair value estimate` 后置数字，漏掉标题中 `HKD 780 Fair Value Unchanged`。
最新港股报告不可验证时停止回退旧文章的保护仍然正确，不能直接删除。
Yahoo 分发源没有接入同一上市口径的港股报告，不把腾讯 ADR 美元值冒充港股估值。

## 修复

- 港股专属标题解析同时支持明确港币数值前置、后置，以及“维持不变”；
  必须有本公司名、公允价值语义和 HKD/HK$。数值从当次页面读取，不新增固定值。
- HTML 转文本保留官方标题和发布时间。新标题中的明确数值优先于旧的人工核验基线。
- 涨跌百分比、其他公司/其他指标、美元 ADR、多个歧义值及历史报告推荐区不能用于填数。
- 正文直接读取超时或失败后继续尝试公共文本读取路径。
- 两条正文读取路径均失败时，可重新读取官方公司报告目录；必须匹配同一 URL、
  上市标识和发布日期，且目录标题明确写出港币公允价值。两次读取必须一致。
  这是同一出版机构的备用读取路径，不是独立数据供应商；没有明确数值仍不猜测。
- 发送前复核重新尝试上次失败的标的；30 分钟内仅复用成功项，避免失败结果阻断恢复。
- 日常正式发送成功后，另外保存仅包含 `state/morningstar_fair_values.json` 的缓存。
  定向试发只读恢复这个估值缓存，仍优先实时取数；既有 48 小时有效期不延长。
  不恢复或保存试发的新闻去重、主题和长期判断状态，也不改收件人或发送计划。
  独立缓存需在本修复上线后的下一次正式日常发送完成后建立；首次缺缓存不阻断试发。

## 核验

- 真实读取腾讯新报告取得 HKD 780、报告日期 2026-09-02；泡泡玛特取得 HKD 224、
  报告日期 2026-08-21。记录只代表本次联网核验，不承诺永远不变。
- 离线回归覆盖不同数值/币种、明确不变、错误公司、百分比、历史报告、超时、
  同源双读不一致、目录日期和上市标识、失败项重试与试发缓存隔离。
- 邮件模板、持仓分组、参考线和 IRR 计算不变；未额外发送邮件。
