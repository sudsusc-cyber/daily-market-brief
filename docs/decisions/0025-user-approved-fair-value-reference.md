# 用户明确指定的公允价值参考

2026-10-04 用户明确要求穆迪采用其提供的 540 美元，直到取得估值日期晚于当天的晨星新值。
此前来源审计未从新报告核实 540，本决策不改变该历史事实。

在 `config/user_fair_value_references.json` 单独保存指定金额、标的/币种、提供日期与替换规则。
提供日期使用北京时间，不伪装成晨星报告日期或官方估值变更日期。
正常刷新与无网络超时回退都应用同一规则，不写入晨星双读核验缓存。

只有通过现有标的身份、币种、来源、金额、日期及双读核验的研究值，且实际估值数据日期
（来源未明确数据截至日时为合格报告日期）严格晚于提供日期，才替换用户参考。上调、下调均适用。
此后已持久保存的较新合格值在取数失败时继续优先，不会重新退回用户参考。
同日、旧数据晚发布、未合格候选均不能覆盖用户参考。

邮件保持公允价值与 IRR 计算口径，表下明确注明用户指定参考；来源说明排除这类参考。
审计标为沿用参考，记录 `source_type=user_provided` 与 `provided_on`，不计为当日已核验。
官方数据日期未知时保留为空，不以用户提供日代替；核验时间和来源 URL 同样不编造。
买入策略、QQQM、泡泡玛特、收件人及发送安排不变。
