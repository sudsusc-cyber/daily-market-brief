# ADR-0017: 情绪温度计核心-辅助权重与历史校准

- 日期:2026-08-17
- 状态:已接受

## 决策

情绪分数继续使用绝对 0–100 量表,但改为核心-辅助结构:

| 指标 | 权重 | 角色 |
| --- | ---: | --- |
| CNN Fear & Greed | 45% | 核心 |
| VIX | 40% | 核心 |
| 高收益债利差 | 8% | 辅助 |
| DXY | 5% | 辅助 |
| Shiller PE | 2% | 慢变量背景 |

五档边界保持 `<25 / 25–40 / 40–60 / 60–75 / >=75`。不采用滚动分位数切档,
避免在持续平静或持续紧张的年份把普通状态错标为“极度”。

## 历史回测

校准窗口为 2021-02-01 至 2026-02-06,取五个序列共同的 1,261 个交易日。
CNN 历史归档在 2021-02-01 之后直接来自其实时端点;早期拼接数据不进入本次
验收窗口。

| 档位 | 天数 | 占比 |
| --- | ---: | ---: |
| 极度恐慌 | 93 | 7.38% |
| 偏冷 | 157 | 12.45% |
| 中性 | 545 | 43.22% |
| 偏热 | 409 | 32.43% |
| 极度贪婪 | 57 | 4.52% |

- 最低分:2025-04-08 为 8.31。
- 最高分:2023-12-19 为 81.09。
- 结论:两个极端档位在真实数据中都可达,同时保持低频,符合“极度”的含义。

## 反向压力测试

为确认 8% 的债利差不会吞掉核心信号,对真实历史观测故意注入反向极值:

- 2025-04-08 其他四项使用真实值,即使把债利差设为最贪婪的 2%,总分仍为
  12.2,属于极度恐慌。
- 2023-12-19 其他四项使用真实值,即使把债利差设为最恐慌的 8%,总分仍为
  76.4,属于极度贪婪。
