# Shared editorial event contracts — 2026-10-01

Audit input: formal run 36814981083, attempt 1, archived source mappings and final
mail. This change repairs classes of editorial failures found in that artifact;
it is not a claim that every sentence in every remote article was independently
verified. No live SMTP send is part of validation.

## Changes

1. Selection, translation and long-term watchpoints now share bilingual event
   families and grammatical-role normalization. Probe inflections remain an
   investigation; investor roles do not invent an investment event; launching an
   inquiry does not imply launching a product. Product debut/unveiling and capital
   authorization are recognized consistently across those stages.
2. Broker ratings and target prices are excluded from company operating news,
   while an independent operating fact in the same source remains eligible.
   Credit ratings are not confused with brokerage advice.
3. Product noun fragments and investor-relations boilerplate are not published
   as complete events. A complete reporting sentence is selected from the same
   immutable source when available. Complete attributed opinions remain eligible.
4. A versioned vocabulary renders standard institutions and places in Chinese
   while preserving product identifiers. Deterministic checks reject swaps of
   known geographical entities. Historical presentation versions stay replayable.
5. Document type is a fact: summary of opinions cannot become meeting minutes.
   Typed source-body context is preferred over an ambiguous headline abbreviation.
6. Corporate actions embedded in market recaps require a dated, complete source
   sentence with action and amount context. Publication dates alone cannot
   establish announcement dates. Remaining authorization, incremental
   authorization and executed repurchases retain separate amount bindings.
   Qualified source dates are archived with their evidence basis.

## Regression scope and limits

Tests include the actual resend source mappings, multiple issuers and action
inflections, correct translations and adversarial changes to event status,
amount scope, dates, geography, boilerplate and complete attributed speech.
Existing source identity, exact excerpts, HTML safety, citation bindings,
negation/modality checks and visible-body-bound long-term judgments remain in
force. Historical rendering contracts are preserved.

These are bounded deterministic checks, not a proof system for arbitrary natural
language. Recap recovery consumes already available identity-bound source
context; it does not guess missing dates or retrieve arbitrary official pages.
Unsupported recaps stay out of publication. New event wording can still require
an explicit rule extension with positive and negative regression cases.

No changes to valuation models, buy rules, recipients, SMTP behavior or schedules.
