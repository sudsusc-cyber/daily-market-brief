# 宏观视野：同类项必须合并

用户于 2026-09-29 明确要求：不管遇到什么情况，只要是同类项，就合并在一起。本约定是持续生效的刊发规则。

## 固定行为

- 每个规范主题在同一期只能出现一个段落。同主题不能因为来源、原始段落、输入次序、重试或完整中文摘录降级而被拆散。
- 按具体主题编排，如“中美关系”“美债市场”“中东局势”，不以重复的“宏观动态”代替分类。
- 每段只出现一次主题标题，完整事实合在该段，全部引用编号统一放在段末。逐事实的原始来源、核验译文和主题继续归档。
- 不强制两三段，不限制每段最多两个来源，不因长度限制拆散同类项或截掉事实。
- 同类不等于重复。不同数字、日期、对象、否定或状态的事实全部保留；仅等价事实可以合并来源。
- 分类只安排事实，不编造事实之间的因果关系，不授权改写未核验的新闻。完全没有合格来源或中文正文时仍使用受控失败提示，不把未经验证的稿件塞进邮件。

## 分类与优先级

`macro_topics.py` 统一处理所有已核验正文；`macro_filter.py` 在模型输出之后重新归并，所以模型自行拆段和错写标题不能绕过规则。

具体议题优先于次要关键词：美债走势即使提到关税、油价或伊朗，仍归美债市场；涉及伊朗、沙特、中东供应的油价、航班、核查归中东局势；中美峰会、对华施压和有明确当期谈判背景的中国自给自足后续稿归中美关系。后续出现新主题时应扩展规范主题及反例测试，不引入一稿一段的例外。暂未识别的稿件集中在单一“其他宏观”段，不假定它们存在因果联系。

## 回归与验收
