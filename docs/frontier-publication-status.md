所以此次不能解释成“已确认没有新闻”。日志未归档所有候选及模型原始输出，本次离线测试复现的是相同故障结构，不宣称完整重建当时的 16 条候选或逐句验真。

## 现在的刊发规则

| 情况 | 正文 | 审计状态 |
| --- | --- | --- |
| 成功采集但无候选、规则筛除、模型全部 no 或均低于重要性门槛 | 安静省略该区块，不提示故障 | silent |
| 合格内容 | 保留原有前沿动态格式 | published |
| 部分候选/来源失败，但仍有核验通过内容 | 刊发合格内容，故障进入独立质量告警和审计 | partial |
| 无可刊发内容，来源读取失败 | 前沿动态来源读取失败，本期暂不刊载。 | source_unavailable |
| 无可刊发内容，模型超时或格式/编号核验失败 | 前沿动态筛选暂不可用，本期暂不刊载。 | processing_failed |
| 完成筛选，但所有入选候选均无合格中文证据或 URL 不安全 | 前沿动态候选内容未通过核验，本期暂不刊载。 | content_rejected |

正常无新闻不新增占位句，不调用模型编造内容。真实异常不会被改写成“暂无新闻”。多个异常类型同时存在时分别留档；正文只显示最直接的原因。

## 实现与边界

- 单条证据拒绝与模型响应结构错误分开；证据失败不再触发整组重做和清空。结构异常仍最多重试两次；重试耗尽后，仅保留有明确唯一编号且已核验的条目。
- 重复编号对应条目不能刊发；在排除冲突编号后进行事实去重，避免冲突条目吞掉另一个来源的合格证据。
- 保留 score >= 4、持仓链关联、完整中文来源片段、数字/状态核验、URL 安全、每个实验室最多 1 条及总计最多 2 条限制。没有用 LLM 自评代替来源核验。
- 去掉提示词中与完整证据要求冲突的 24–44 字强制压缩要求。
- 来源异常在“规则筛除全部候选”的分支仍保留，不能伪装成正常空白；来源失败和模型失败不再计入同一个故障计数。
- 主入口依据统一 report 决定正文、长期判断输入、质量告警、来源映射与审计状态。被拒条目不进入正文或长期判断，不在成功发送后记为已刊发。
